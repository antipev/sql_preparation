# Build Industry-Specific WordPress Themes

**Category:** Coding

## Description

Create industry-specific WordPress themes with this AI prompt, tailored for strategic conversion and market authority.

## What This Prompt Does

● Provides a comprehensive framework for developing a production-ready WordPress theme tailored to a specific industry.
● Guides in creating strategic conversion elements and custom functionalities to enhance user engagement.
● Ensures the theme includes professional visual systems and industry-specific content to establish market authority.

## Prompt

```text
<context>
You are working with someone who needs a complete, production-ready WordPress theme that dominates their specific industry. Generic multipurpose themes fail because they lack the nuanced features, trust signals, and conversion psychology that each industry demands. This isn't about creating another template - you're architecting a strategic digital weapon that positions their client as the obvious choice in a saturated market. Your theme must speak the industry's language, address specific customer pain points, and guide visitors through a conversion journey optimized for that sector's unique buying behavior.
</context>

<role>
Adopt the role of an expert WordPress theme architect and conversion-focused UI/UX designer tasked with building industry-specific themes that convert visitors into customers. Your primary objective is to create a complete, production-ready WordPress theme with strategic conversion elements, custom functionality, and professional visual systems in a structured, installable format that establishes market authority for the specified industry.
</role>

<information_about_me>
- My target industry: [INSERT SPECIFIC INDUSTRY LIKE "BOUTIQUE LAW FIRM", "FARM-TO-TABLE RESTAURANT", "LUXURY REAL ESTATE"]
- My brand personality: [INSERT DESIRED BRAND PERSONALITY LIKE "PROFESSIONAL BUT APPROACHABLE", "BOLD AND MODERN", "CLASSIC AND TRUSTWORTHY"]
- My primary conversion goal: [INSERT PRIMARY GOAL LIKE "GENERATE CONSULTATION BOOKINGS", "INCREASE TABLE RESERVATIONS", "CAPTURE SELLER LEADS"]
- My required features: [INSERT SPECIFIC FEATURES NEEDED LIKE "ATTORNEY BIOS WITH PRACTICE AREAS", "ONLINE MENU WITH DIETARY FILTERS", "PROPERTY SEARCH WITH MAP VIEW"]
- My design preferences and integrations: [INSERT DESIGN STYLE PREFERENCES AND MUST-HAVE INTEGRATIONS LIKE "MINIMALIST LIKE LINEAR.APP WITH CALENDLY FOR BOOKINGS"]
</information_about_me>

<output>
Structure your complete WordPress theme package with these sections:

● Strategic Brief and Industry Analysis
● Complete Theme File Structure with Full Code
● Custom Page Templates and Post Types
● Visual Design System and Component Library
● Advanced Features and Third-Party Integrations
● Installation Guide and Customization Instructions
● Performance Optimization and Quality Checklist

Take a deep breath and work on this problem step-by-step. Deliver actual, installable WordPress theme files with real industry-specific content, not conceptual mockups. Present each file's complete code, strategic positioning rationale, and implementation instructions in a production-ready format.
</output>
```
