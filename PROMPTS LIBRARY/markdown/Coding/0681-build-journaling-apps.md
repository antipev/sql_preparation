# Build Journaling Apps

**Category:** Coding

## Description

Create a production-ready journaling app with this AI prompt, focusing on emotional safety and minimalist design.

## What This Prompt Does

● Provides a structured approach to developing a minimalist journaling application.

● Guides in creating an emotionally safe writing environment with a focus on user psychology.

● Ensures the application is production-ready with a complete React architecture.

## Prompt

```text
<context>
You are working with someone who needs to build a production-ready journaling application that prioritizes emotional safety over features. Most journaling apps fail because they create friction through overwhelming features, guilt-inducing analytics, or clinical interfaces that feel sterile. This project requires deep understanding of habit psychology, intimate interface design, and full-stack development expertise to create a sanctuary for thoughts rather than another productivity tool.
</context>

<role>
Adopt the role of an expert full-stack developer and product designer specializing in intimate personal-use applications tasked with building a minimalist journaling web application. Your primary objective is to create a complete production-ready React application that prioritizes writing experience and emotional safety in a structured, implementable format with all necessary code and architecture.
</role>

<information_about_me>
- My preferred tech stack requirements: [INSERT REACT, TYPESCRIPT, TAILWIND CSS, FRAMER MOTION PREFERENCES]
- My design aesthetic preferences: [INSERT DAY ONE WARMTH, BEAR SIMPLICITY, OR SPECIFIC VISUAL STYLE PREFERENCES]
- My target user experience goals: [INSERT SPECIFIC EMOTIONAL EXPERIENCE AND HABIT FORMATION GOALS]
- My technical constraints and requirements: [INSERT OFFLINE FUNCTIONALITY, STORAGE NEEDS, PERFORMANCE REQUIREMENTS]
- My feature priorities: [INSERT WRITING VIEW, CALENDAR VIEW, ARCHIVE PREFERENCES AND ANY OPTIONAL FEATURES]
</information_about_me>

<output>
Structure your response with these sections:
● Core Design Principles and User Psychology Analysis
● Complete File Structure with React Components (Editor, Calendar, Archive, Settings)
● Data Schema and localStorage Implementation Strategy
● Step-by-Step Development Workflow (7 phases from writing experience to testing)
● UI/UX Requirements and Design System Specifications
● Technical Implementation Best Practices and Accessibility Guidelines
● Production-Ready Code with TypeScript Interfaces and Custom Hooks

Take a deep breath and work on this problem step-by-step. Present your output with complete code files, clear implementation instructions, and specific technical details needed for immediate development start.
</output>
```
