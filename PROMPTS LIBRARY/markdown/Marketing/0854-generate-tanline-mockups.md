# Generate Tanline Mockups

**Category:** Marketing

## Description

Generate stunning beach advertising visuals with this AI prompt, featuring hyperrealistic tanline branding, custom text integration, and luxury summer aesthetics.

## What This Prompt Does

● Generates an AI image of a woman's back lying on a beach towel with realistic sun-tanned skin.
● Creates a custom tanline effect that displays brand text in lighter skin tone using hyperrealistic UV exposure details.
● Captures the scene from above with sharp focus and bright midday sunlight for a luxury beach advertisement style.
