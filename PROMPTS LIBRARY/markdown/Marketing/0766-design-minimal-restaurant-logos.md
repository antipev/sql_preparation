# Design Minimal Restaurant Logos

**Category:** Marketing

## Description

Design elegant restaurant logos with this AI prompt, featuring minimal style, custom icons, refined typography, and scalable formats for menus and branding.

## What This Prompt Does

● Generates an AI image of a minimal restaurant logo combining an abstract icon with clean typography.
● Uses warm and elegant brand colors on a flat design with no gradients or shadows.
● Creates a scalable combination mark suitable for menus, signage, and social media use.

## Prompt

```text
{
  "project": "Logo Design",
  "sector": "Restaurant / Café",
  "inputs": {
    "company_name": "[RESTAURANT NAME]",
    "cuisine_type": "[CUISINE TYPE]",
    "brand_traits": ["warm", "authentic", "elegant"],
    "color_palette": "[BRAND COLORS]",
    "logo_type": "Combination mark"
  },
  "design_rules": {
    "style": "Minimal, timeless",
    "icon_idea": "Abstract symbol inspired by the restaurant name or cuisine identity",
    "typography": "Clean serif or refined script",
    "background": "White or transparent",
    "no_gradients": true,
    "no_shadows": true,
    "flat_design": true
  },
  "output": {
    "format": "Flat logo",
    "scalability": "Readable at small sizes",
    "usage": ["menu", "signage", "social media"]
  }
}
```
