# Design Luxury Cosmetic Logos

**Category:** Marketing

## Description

Design stunning beauty brand logos with this AI prompt, featuring clean luxury aesthetics, elegant typography, and scalable formats for packaging and digital use.

## What This Prompt Does

● Generates a clean luxury AI image of a beauty brand logo using elegant typography and minimal shapes.

● Creates a flat design wordmark or symbol that works on white or transparent backgrounds without textures.

● Produces a scalable logo AI image optimized for cosmetic packaging, websites, and social media use.

## Prompt

```text
{
  "project": "Logo Design",
  "sector": "Beauty / Cosmetics",
  "inputs": {
    "brand_name": "[BRAND NAME]",
    "brand_traits": ["clean", "luxurious", "sensory"],
    "color_palette": "[BRAND COLORS]",
    "logo_type": "Wordmark or symbol"
  },
  "design_rules": {
    "style": "Clean luxury",
    "icon_idea": "Minimal abstract shape or letterform",
    "typography": "Elegant modern serif",
    "background": "White or transparent",
    "no_textures": true,
    "flat_design": true
  },
  "output": {
    "format": "Flat logo",
    "scalability": "Clear on product packaging",
    "usage": ["packaging", "website", "social"]
  }
}
```
