# Create Minimal Line Art Illustrations

**Category:** Marketing

## Description

Create minimal hand-drawn illustrations with this AI prompt, featuring bold line art, customizable colors, centered composition, and stylized simplicity.

## What This Prompt Does

● Generates a minimal hand-drawn AI image with bold, smooth line art in a centered composition.
● Uses thick, slightly imperfect strokes without shading, gradients, or texture for an authentic sketch feel.
● Creates a simplified subject on a warm off-white background with customizable line colors and high-resolution output.

## Prompt

```text
{
  "task": "minimal_hand_drawn_illustration",
  "style": {
    "illustration_type": "hand_drawn_line_art",
    "line_style": "bold_smooth_contours",
    "stroke_weight": "thick_and_consistent",
    "line_quality": "slightly_imperfect_human_sketch",
    "no_shading": true,
    "no_gradients": true,
    "no_texture": true
  },
  "color_palette": {
    "line_color": "[LINE COLOR]",
    "background_color": "warm_off_white"
  },
  "subject": {
    "object_name": "[SUBJECT]",
    "view_angle": "front_view",
    "simplification": "stylized_minimal"
  },
  "composition": {
    "layout": "single_object_centered",
    "background": "plain"
  },
  "output": {
    "aspect_ratio": "1:1",
    "resolution": "high"
  }
}
```
