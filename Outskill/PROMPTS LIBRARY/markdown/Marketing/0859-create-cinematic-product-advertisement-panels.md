# Create Cinematic Product Advertisement Panels

**Category:** Marketing

## Description

Create ultra-wide cinematic advertisements with this AI prompt, featuring luxury product panels, nighttime photography, precision optics, and elite brand storytelling.

## What This Prompt Does

● Creates a luxury three-panel ultra-wide AI image showcasing a premium telescope in cinematic nighttime scenes.

● Generates three connected scenes that display the product on a starlit cliff, a user observing stars, and a detailed lens close-up.

● Produces a high-end advertisement AI image with astrophotography realism and sophisticated lighting for tech marketing campaigns.
