# Design Minimal Geometric Logos

**Category:** Marketing

## Description

Design professional logos with this AI prompt, featuring minimal geometric styles, brand-aligned colors, and scalable formats for web and mobile applications.

## What This Prompt Does

● Generates a minimal geometric AI image of a combination mark logo with company name and symbol merged together.

● Creates a flat design with symmetrical shapes on white background using specified brand colors without textures or gradients.

● Produces a scalable logo optimized for digital use including favicons and app icons with clean professional appearance.

## Prompt

```text
{
  "project": "Logo Design",
  "inputs": {
    "company_name": "[COMPANY NAME]",
    "company_sector": "[INDUSTRY]",
    "brand_personality": ["modern", "reliable", "innovative"],
    "color_palette": "[BRAND COLORS]",
    "logo_type": "Combination mark",
    "style": "Minimal geometric",
    "usage": "Web and mobile app"
  },
  "design_rules": {
    "background": "White",
    "complexity": "Low",
    "geometry": "Symmetrical and clean",
    "scalability": "Optimized for favicon and app icon",
    "no_textures": true,
    "no_gradients": true,
    "no_shadows": true,
    "no_mockups": true
  },
  "output": {
    "format": "Flat logo design",
    "alignment": "Centered",
    "final_feel": "Clean, tech-forward, professional"
  }
}
```
